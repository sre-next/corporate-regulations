# ライセンス遵守ガイドライン

このガイドラインは、当法人の理事、職員および運営メンバー（スタッフ・当日スタッフ）が当法人の活動で使用するソフトウェアや機器などについて、ライセンスおよび利用規約の遵守事項を定めるものです。

## 第 1 条（ライセンス・利用規約の遵守）

ソフトウェアや機器、外部サービスなどは、ライセンスおよび利用規約を守って使用します。次のものの使用と持ち込みを禁止します。

1. 不正に複製または入手したもの
2. ライセンスまたは利用規約が確認できないもの

## 第 2 条（事前の承認）

提供元との契約や取り決めが必要な機器やサービスを導入する場合は、事前に理事の承認を得ます。
